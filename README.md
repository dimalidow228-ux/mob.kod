# Random Password Generator

**Автор:** Орехов Дмитрий

## Описание

Random Password Generator - это графическое приложение на Python для генерации безопасных случайных паролей с возможностью настройки параметров и сохранением истории генерации.

### Возможности

- Генерация случайных паролей длиной от 4 до 32 символов
- Выбор типов символов:
  - Цифры (0-9)
  - Буквы (A-Z, a-z)
  - Специальные символы (!@#$%^&*_+)
- Визуальный ползунок для выбора длины пароля
- Копирование сгенерированного пароля в буфер обмена
- Сохранение истории паролей в JSON файл
- Загрузка истории при запуске приложения
- Таблица истории с деталями (дата, длина, типы символов)
- Очистка истории

## Требования

- Python 3.6+
- Модули: tkinter (входит в стандартную библиотеку Python), random, string, json, os, datetime
